A single-line joke pickup line aimed at a robot/AI, written for the
[Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)
bounty on [make.fun](https://make.fun).

## The line

> Are you gradient descent? Because every time I see you, I fall a little further.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt`, validating the bounty gate first: UTF-8 text, 1–200
characters, not only whitespace, a single line.

```sh
node main.ts
```
